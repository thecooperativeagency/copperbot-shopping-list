# CopperBot Shopping & Build List

A persistent shopping and build list for Lance Faucheux's CopperBot project: a slim 78 × 60 × 12.7 mm handheld voice-endpoint device with a 3D-printed enclosure.

- `index.html`: a single self-contained page (inline CSS; only external resource is an optional Google Font, Inter). Open it in any browser; it works offline with a system-font fallback.

## Editing

- Each section is a plain HTML table or list, so you can edit it directly.
- Status markers: `☑ Ordered` (class `ordered`), `☐ To buy` (class `tobuy`), `☐ To do` (class `todo`), `✕ Skip` (class `skip`). When an item is ordered or done, change the text and set the class to `ordered`.
- Update the "Last updated" line in the header whenever you change anything.
- Never put passwords, tokens, API keys, or other credentials on this page.
